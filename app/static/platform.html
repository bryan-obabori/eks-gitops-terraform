Platform components

Each layer has a specific responsibility

Provisioning

Terraform

Defines the AWS network, EKS cluster, IAM, and platform bootstrap resources.

Orchestration

Amazon EKS

Runs the Kubernetes control plane and schedules the containerized application workload.

Identity

EKS Pod Identity

Provides scoped AWS permissions to the load balancer controller without broad node-role access.

Ingress

AWS Load Balancer Controller

Translates Kubernetes Ingress intent into an AWS Application Load Balancer.

Delivery

Argo CD

Continuously reconciles the application state declared in Git.

Workload

Go + Docker

The application is packaged as an immutable container and deployed as a Kubernetes workload.
