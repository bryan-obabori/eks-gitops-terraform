One repository, complete delivery flow

Infrastructure

Terraform + AWS EKS

The AWS network, Kubernetes cluster, IAM relationships, and platform components are provisioned declaratively.

Delivery

GitHub Actions + Argo CD

Application changes are tested, containerized, published, and reconciled into the cluster through GitOps.

Networking

Private Workers + AWS ALB

Application workloads run on private EKS workers while an AWS Application Load Balancer provides ingress.
